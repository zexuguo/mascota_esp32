# mascota_esp32

Mascota de escritorio con IA en una ESP32-S3 con pantalla de 2,8" (LCDWiki ES3C28P).
Proyecto para aprender: la guía paso a paso está en el vault de Obsidian
(`007 Proyectos/ESP32-Pantalla/Guia/`).

| Carpeta | Para qué |
|---|---|
| `prueba/` | Experimentos rápidos (lecciones 1-3) |
| `mascota/` | La mascota (desde la lección 4) |
| `pc-companion/` | Programas de Python del PC (lecciones 9 y 12) |
| `backup/` | Copia del firmware de fábrica (no se sube a git) |
